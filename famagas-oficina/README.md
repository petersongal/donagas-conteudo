# Oficina FamaGás

Conteúdo do Instagram **@famagas_** (Reels com o mascote animado). Fica nesta pasta do repositório de conteúdo porque ele já tem a chave da fal.ai.
Não tem relação com as peças do @appdonagas do resto do repositório.

- `agenda.json`: fila de Reels lida pelo publicador do site famagas.com.br.
- `reels/`: fábrica (ver `reels/LEIA-ME.md`). `posts/<id>/`: vídeo, capa e conferência.
- `metricas/relatorio.json`: números de cada post, a cada 3 horas.
- `ESTRATEGIA-CRESCIMENTO.md`: metas, regras e diário de testes.
