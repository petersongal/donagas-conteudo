# famagas-conteudo

Conteúdo do Instagram **@famagas_** que entra no ar sozinho, sem depender do Publish do site.

- `agenda.json`: fila de publicações (hoje: Reels). O publicador do site famagas.com.br lê este arquivo a cada rodada.
- `reels/`: fábrica de Reels com o mascote animado (ver `reels/LEIA-ME.md`).
- `posts/<id>/`: vídeo (`reel.mp4`), capa e conferência de cada Reels.
- `metricas/relatorio.json`: números de cada post, atualizados a cada 3 horas.
- `ESTRATEGIA-CRESCIMENTO.md`: metas, regras e diário de testes. **Toda tarefa lê este arquivo antes de criar conteúdo.**
