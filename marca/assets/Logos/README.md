# Logos

Todos em PNG com fundo transparente, prontos para Canva e Photoshop.

- **logo-horizontal-fundo-claro**: chama rosa, Dona marinho, GÁS rosa. Para fundo branco ou rosa-fundo.
- **logo-horizontal-fundo-escuro**: Dona branco, GÁS rosa. Para fundo marinho.
- **logo-horizontal-branco**: uma tinta, para fundo rosa-marca ou foto escura.
- **logo-horizontal-marinho**: uma tinta, para fundo rosa-claro ou impressão em uma cor.
- **logo-horizontal-rosa**: uma tinta, para fundo marinho.
- **logo-icone-colorido**: chama oficial do app. Foto de perfil, favicon, ícone.
- **logo-icone-branco / marinho / rosa**: a chama em uma tinta só.

Tinta única: a cor do arquivo é a cor do logo (branco, marinho ou rosa). Não use currentColor.
