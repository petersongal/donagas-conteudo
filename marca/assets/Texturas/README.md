# Texturas

Todo fundo da Dona Gás leva uma textura discreta. Nunca use fundo liso e vazio.

| Arquivo | Onde usar | Cor de base |
| --- | --- | --- |
| textura-listras-marinho.svg | capas e stories escuros | marinho #171276 com listras brancas a 5,5% |
| textura-pontos-rosa-claro.svg | slides internos de carrossel | rosa fundo #FFF1F8 com pontos marinho a 14% |
| textura-pontos-rosa.svg | slides em rosa (tela do app, CTA) | rosa #FF47A3 com pontos brancos a 16% |

As listras ficam a 55 graus (no Canva, gire a textura a 55). A chama gigante do logo pode aparecer ao fundo a 8% de opacidade, sempre cortada pela borda.
