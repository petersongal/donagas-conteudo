# Dona Gás — conteúdo do Instagram (@appdonagas)

Repositório público lido pelo publicador automático (função `instagram-publisher` do App Dona Gás).

- `agenda.json`: lista de publicações `{id, tipo: carrossel|imagem|story, abordagem, legenda, imagens: [caminhos .jpg], agendado_para (ISO com fuso), aprovado}`.
- `posts/<id>/<n>.jpg`: artes em JPEG (feed 1080×1350, story 1080×1920).
- `marca/`: logo, mascotes (PNG transparente), texturas e o guia de marca.

Não coloque tokens, chaves ou dados de clientes aqui: o repositório é público.
